==================================================================
รายละเอียดการเปลี่ยนแปลง
==================================================================

สร้างโปรเจกต์ครั้งแรกตาม skill "qm-pattern-signal-bot"

ตัดสินใจหลักที่ถามผู้ใช้ก่อนเริ่มเขียน:
  - สถาปัตยกรรม: Python scanner ล้วน (ไม่ใช้ TradingView/Pine, ไม่มีค่าใช้จ่ายรายเดือน)
  - เหรียญ: BTC + ETH + Top 20 ตามวอลุ่ม 24 ชม. (ดึงอัตโนมัติ)
  - ทองคำ (XAUUSD): ยังไม่ทำในเวอร์ชันแรก
  - LINE: push หาตัวเองแบบ 1:1
  - เก็บรูปกราฟ: Cloudflare R2

ไฟล์ที่สร้าง:
  qm_detector.py    คัดลอกจาก skill ไม่แก้ไขเลย — ตรวจจับโครงสร้าง QM
                    (LS/L1/HEAD/BOS/RS) คำนวณ Entry/SL/TP/RR ป้องกัน repaint
  divergence.py     [ใหม่] ยืนยัน QM ด้วย RSI divergence ระหว่างจุด LS กับ HEAD
                    ก่อนส่งสัญญาณ (ตามที่ผู้ใช้ต้องการให้ยืนยันซ้ำอีกชั้น)
  universe.py       [ใหม่] ดึง Top 20 เหรียญ USDT ตามวอลุ่มจาก Binance
                    พร้อม cache 24 ชม.
  chart_renderer.py ขยายจาก skill — เพิ่มพาเนล RSI และเส้น divergence
                    ลงบนรูปกราฟ (ตามที่ผู้ใช้ขอให้วาดเส้นบนรูป)
  chart_uploader.py [ใหม่] อัปโหลด PNG ขึ้น Cloudflare R2 ผ่าน boto3
  line_notifier.py  จาก skill + เพิ่มแถว Divergence ใน Flex bubble
  state.py          SQLite กันส่งสัญญาณซ้ำ (key = timestamp ของแท่ง HEAD)
  bot.py            ตัวสแกนหลัก
  webhook_capture.py [ใหม่] ใช้ครั้งเดียวเพื่อดึง LINE userId
  backtest.py       คัดลอกจาก skill
  config.yaml, README.md, requirements.txt, .env.example, .gitignore

การแก้ไขระหว่างทาง:
  - พบว่า Top 20 ตามวอลุ่มมี stablecoin pair ปนมา (USDC/USDT, RLUSD/USDT ฯลฯ)
    ซึ่งราคาแทบไม่ขยับ ไม่มีทางเกิด QM จริง จึงเพิ่มตัวกรองออก

ทดสอบแล้ว: ตรวจจับเจอ 4 สัญญาณบน BTC/USDT 1H, วาดกราฟถูกต้อง,
ส่งเข้า LINE จริงสำเร็จ (ทดสอบด้วยสัญญาณย้อนหลังติดป้าย TEST)
