เวอร์ชัน: v1.1.0
วันที่: 2026-08-17
สรุป: เพิ่ม CLI จัดการบอท (start/stop/status/logs) + log แยกไฟล์รายวัน
เทียบกับ: v1.0.1

==================================================================
รายละเอียดการเปลี่ยนแปลง
==================================================================

ผู้ใช้ต้องการให้บอทรันทุก 1 ชั่วโมง โดยมีคำสั่งเริ่ม/หยุด แสดง log ระหว่างทำงาน
และเก็บ log เป็นไฟล์ text แยกตามวัน

  qmbotctl.py     [ใหม่] คำสั่ง start / stop / status / logs
                  - start: รันเบื้องหลังแล้วแสดง log สดต่อทันที
                  - stop: หยุดแบบ graceful (SIGTERM) มี fallback บังคับปิด
                  - logs -f: ดู log สดจากเทอร์มินัลไหนก็ได้
  logging_setup.py [ใหม่] DailyFileHandler เขียน log ลง logs/YYYY-MM-DD.log
                  เปลี่ยนไฟล์เองอัตโนมัติตอนเที่ยงคืน

  ไม่ใช้ cron เพราะ bot.py --loop มีกลไกตั้งเวลาในตัวอยู่แล้ว

บั๊กที่เจอตอนทดสอบและแก้แล้ว:
  1. log ถูกเขียนซ้ำเข้า qmbot.crash.log เพราะ console handler เขียนลง stderr
     ซึ่งถูก redirect ไปไฟล์ crash log ด้วย → แก้ให้เขียนลง stdout แทน
  2. คำสั่ง logs -f ไม่แสดงผลสดจริง เพราะ Python buffer stdout เต็มบล็อก
     เมื่อไม่ได้รันจาก terminal โดยตรง → แก้ด้วยการบังคับ line-buffering

==================================================================
ไม่มีสำเนาโค้ดสำหรับเวอร์ชันนี้

เวอร์ชันนี้เกิดขึ้นก่อนจะเริ่มใช้ระบบเก็บเวอร์ชัน โค้ดตอนนั้นถูกแก้ทับ
ไปแล้วและไม่ได้ commit แยกไว้ จึงกู้กลับมาไม่ได้ การสร้างขึ้นใหม่ย้อนหลัง
จะได้ไฟล์ที่ไม่เคยถูกทดสอบจริง จึงเก็บไว้แค่บันทึกการเปลี่ยนแปลง
==================================================================
