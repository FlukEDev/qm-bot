เวอร์ชัน: v1.1.1
วันที่: 2026-08-17
สรุป: แก้บั๊ก: กด Ctrl+C แล้วบอทที่รันเบื้องหลังหยุดตามไปด้วย
เทียบกับ: v1.1.0

==================================================================
รายละเอียดการเปลี่ยนแปลง
==================================================================

ผู้ใช้รายงานว่าหลังสั่ง start แล้วกด Ctrl+C บอทหยุดทำงานเอง

สาเหตุ: bot.py ไม่ได้ป้องกันตัวเองจากสัญญาณ SIGINT เลย ถึงแม้ qmbotctl.py
จะแยก process ออกเป็น session ของตัวเองแล้ว แต่ถ้ามีทางที่ Ctrl+C หลุดไปถึงได้
(terminal/shell บางแบบ, tmux ซ้อน ฯลฯ) ค่าเริ่มต้นของ Python คือปิดโปรแกรมทันที

วิธีแก้: เมื่อรันด้วย --loop (คือตอนทำงานเบื้องหลัง) ให้ bot.py เพิกเฉยต่อ SIGINT
เหลือแค่ qmbotctl.py stop (ส่ง SIGTERM) เท่านั้นที่หยุดได้

ทดสอบ 2 แบบ: จำลอง Ctrl+C จริง และส่ง SIGINT ตรงเข้า bot.py — รอดทั้งคู่

[แก้ไข]
  - bot.py

ไปแล้วและไม่ได้ commit แยกไว้ จึงกู้กลับมาไม่ได้ การสร้างขึ้นใหม่ย้อนหลัง
จะได้ไฟล์ที่ไม่เคยถูกทดสอบจริง จึงเก็บไว้แค่บันทึกการเปลี่ยนแปลง
