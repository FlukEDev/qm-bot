==================================================================
รายละเอียดการเปลี่ยนแปลง
==================================================================

ผู้ใช้รายงานว่าสั่ง status แล้วขึ้นว่าหยุดทำงาน ทั้งที่เพิ่งสั่ง start ไป

สาเหตุ: ผู้ใช้รัน `python3 qmbotctl.py start` โดยไม่ได้ activate venv
qmbotctl.py เองใช้แค่ standard library จึงรันผ่าน แต่ตอนมันสั่งให้ bot.py ทำงาน
มันใช้ python3 ตัวเดียวกัน (ที่ไม่มี pandas/ccxt) → bot.py ตายทันทีด้วย
ModuleNotFoundError โดย error ไปโผล่เงียบๆ ใน qmbot.crash.log

วิธีแก้ 2 จุด:
  1. qmbotctl.py หา interpreter จาก .venv/bin/python ของโปรเจกต์เองเสมอ
     ไม่ว่าจะถูกเรียกด้วย python อะไรก็ตาม
  2. ถ้า bot.py เริ่มแล้วตายทันที ให้ start แสดง error + traceback ทันที
     ไม่ต้องให้ผู้ใช้ไปเปิดหา crash log เอง
