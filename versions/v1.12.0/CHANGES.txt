สรุป: เพิ่มเกรด A/B/C จาก divergence บน swing สุดท้ายของ QM (BOS→RS)
เทียบกับ: v1.11.0

==================================================================
รายละเอียดการเปลี่ยนแปลง
==================================================================

ผู้ใช้เสนอให้ตรวจ divergence บน swing สุดท้ายของรูปแบบ QM เพื่อเพิ่มความแม่นยำ

เดิมบอทเช็ค divergence ระหว่าง LS กับ HEAD (สองยอดแรกที่ประกอบเป็น liquidity
sweep) ส่วนที่เพิ่มคือขาสุดท้าย: ราคาเด้งจาก BOS กลับขึ้นมาที่ QML (จุด RS)
คำถามคือการเด้งครั้งนั้นยังมีแรงเหลืออยู่ไหม

ทดสอบสองสมมติฐานที่ตีความตรงข้ามกัน (บนข้อมูล 830,000 แท่ง 15 เหรียญ 6.6 ปี):
  A) RSI ที่ RS ต่ำกว่าที่ HEAD = โมเมนตัมหมดแรง -> น่าจะกลับตัวจริง
  B) RSI ที่ RS สูงกว่าที่ HEAD = hidden divergence -> เทรนด์ลงไปต่อ

ผล: A ถูก B ผิดชัดเจน
  ตัวกรอง                  in-sample        out-of-sample
  baseline (ไม่กรอง)       +0.434R (1154)   +0.473R (551)
  A  diff > 0              +0.535R  (474)   +0.734R (245)
  A+ diff > 5              +0.657R  (253)   +1.031R (132)  win 53.8% PF 2.94
  B  diff < 0              +0.364R  (680)   +0.265R (306)  <- แย่กว่า baseline

เกณฑ์ 4-6 อยู่บนที่ราบเดียวกัน (OOS 0.93-1.03) ค่า 5 จึงไม่ใช่จุดฟลุก

วิธี implement — ให้เกรดแทนการกรองทิ้ง:
  ตัวกรอง A+ ตัดสัญญาณทิ้งถึง 78% ซึ่งขัดกับที่ผู้ใช้ระบุไว้ชัดเจนใน v1.10.0
  ว่าอยากเห็นทุกสัญญาณแล้วตัดสินใจเอง และทุกเกรดยังกำไรเป็นบวกทั้งหมด
  จึงทำเป็นระบบให้เกรด A/B/C ติดไปกับสัญญาณแทน:

    เกรด        in-sample          out-of-sample
      A         +0.657R (253)      +1.031R (132)  win 53.8%
      B         +0.396R (221)      +0.386R (113)
      C         +0.364R (680)      +0.265R (306)
  เรียงลำดับถูกต้องสม่ำเสมอทั้งสองช่วง = ใช้ตัดสินใจได้จริง
  จำนวนสัญญาณรวมไม่เปลี่ยน (1154 / 551 เท่าเดิม) ไม่มีอะไรถูกตัดทิ้ง

  ถ้าภายหลังอยากให้กรองจริง ตั้ง divergence.last_swing.min_diff เป็นตัวเลขได้
  (เช่น 5 เพื่อเอาเฉพาะเกรด A)

สิ่งที่เปลี่ยน:
  divergence.py   เพิ่ม last_swing_momentum() และ grade_last_swing()
                  attach_divergence() รับพารามิเตอร์เกรดและตัวกรองเพิ่ม
  config.yaml     เพิ่มบล็อก divergence.last_swing
  line_notifier.py แสดงแถวเกรดในข้อความ LINE พร้อมคำอธิบายภาษาไทย
                  เช่น 'เกรด A | โมเมนตัมหมดแรงชัด (RSI -7)'
  bot.py          ส่งค่า config เข้า attach_divergence และ log เกรด

ทดสอบ: dry-run จับสัญญาณจริง ZRO/USDT 4h เกรด C (RSI -10.2) ได้ถูกต้อง
deploy ขึ้น VM แล้ว สแกนผ่านไม่มี error
