สรุป: วาดเส้น divergence ของ swing สุดท้ายลงบนกราฟ พร้อมแสดงเกรดบนหัวกราฟ
เทียบกับ: v1.12.0

==================================================================
รายละเอียดการเปลี่ยนแปลง
==================================================================

ผู้ใช้ขอให้เพิ่มเส้น divergence ของ swing สุดท้ายลงบนรูปก่อนส่งเข้า LINE

v1.12.0 คำนวณและให้เกรด A/B/C จาก swing สุดท้ายแล้ว แต่แสดงเฉพาะในข้อความ
ส่วนบนรูปกราฟยังมีแค่เส้น divergence เส้นแรก (LS -> HEAD) เท่านั้น

สิ่งที่เพิ่มใน chart_renderer.py:
  - เส้นที่ 2 บนพาเนล RSI ลากจาก HEAD ไปยัง RS(trigger) ซึ่งเป็นขาสุดท้าย
    ของรูปแบบ และเป็นที่มาของเกรด
  - ใช้สีตามเกรดเพื่อไม่ให้สับสนกับเส้นแรก (สีเหลือง):
        A = เขียว (#26a69a)  เส้นทึบ
        B = ส้ม   (#ff9800)  เส้นทึบ
        C = เทา   (#8c8c8c)  เส้นประ
  - ติดหมายเลขกำกับทั้งสองเส้นให้อ่านง่าย:
        '1. Bearish Div'  และ  '2. Last swing -> A (+15 RSI)'
  - เพิ่ม 'Grade A' ต่อท้ายหัวกราฟ

ตรวจสอบแล้วทั้ง 3 เกรด เรนเดอร์ถูกต้องและแยกแยะเส้นได้ชัดเจน:
    A  BTC/USDT 1h short bearish  ls_diff=+14.6
    B  SOL/USDT 1h short bullish  ls_diff=+1.5
    C  BTC/USDT 1h short bullish  ls_diff=-31.9

deploy ขึ้น VM แล้ว และส่งตัวอย่างเข้า LINE ให้ผู้ใช้ดูแล้ว
