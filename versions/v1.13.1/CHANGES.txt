สรุป: ย่อข้อความโมเมนตัมใน LINE ให้สั้นลง และแก้เครื่องหมาย RSI ที่ผิดฝั่ง BUY
เทียบกับ: v1.13.0

==================================================================
รายละเอียดการเปลี่ยนแปลง
==================================================================

ผู้ใช้แจ้งว่าข้อความส่วนโมเมนตัมยาวเกินไป ขอให้สั้นลง เช่น 'สูง (RSI)'

ก่อน -> หลัง:
    เกรด A | โมเมนตัมหมดแรงชัด (RSI -7)   ->   เกรด A | สูง (RSI +15)
    เกรด B | อ่อนแรงเล็กน้อย (RSI -5)      ->   เกรด B | กลาง (RSI +1)
    เกรด C | ยังมีแรงสวน                   ->   เกรด C | ต่ำ (RSI -20)

พร้อมกันนี้แก้บั๊กที่พบระหว่างทาง:
  โค้ดเดิมใส่เครื่องหมายลบตายตัว f'(RSI -{ls_diff})' ซึ่งถูกเฉพาะฝั่ง SELL
  เพราะค่า ls_diff ถูก normalize ตามทิศทางแล้ว (บวก = โมเมนตัมอ่อนลงในทิศที่เทรด)
  สำหรับสัญญาณ BUY โมเมนตัมที่ดีคือ RSI ต้อง 'เพิ่มขึ้น' การโชว์เครื่องหมายลบ
  จึงสื่อความหมายตรงข้ามกับความจริง
  แก้เป็น f'{ls_diff:+.0f}' ให้แสดงเครื่องหมายตามค่าจริง

  ตรวจสอบแล้วทั้ง 6 กรณี (A/B/C x BUY/SELL) แสดงเครื่องหมายถูกต้องทั้งหมด
  เช่น BUY เกรด A -> 'สูง (RSI +9)' และ BUY เกรด C -> 'ต่ำ (RSI -32)'

เกรด C ตอนนี้แสดงค่า RSI ด้วย (เดิมไม่แสดงเลย) ทำให้เห็นว่าโมเมนตัมสวนแรงแค่ไหน
