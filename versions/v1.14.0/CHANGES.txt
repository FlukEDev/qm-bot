สรุป: เพิ่มสรุปเทรนด์ Bitcoin รายวัน ส่ง LINE ทุก 10 โมงเช้า

==================================================================
รายละเอียดการเปลี่ยนแปลง
==================================================================

ผู้ใช้ขอ 2 อย่าง: สรุปข่าว crypto รายสัปดาห์ (ทุกวันจันทร์) และสรุปเทรนด์ BTC
รายวัน เวลา 10 โมงเช้า

หลังจากอธิบายว่าส่วนสรุปข่าวต้องพึ่งแหล่งข่าวภายนอก และถ้าอยากได้สรุปเป็นย่อหน้า
ภาษาไทยจริงๆ ต้องใช้ Claude API (มี API key + ค่าใช้จ่าย) ผู้ใช้ตัดสินใจ
ไม่ทำส่วนข่าวแล้ว เหลือเฉพาะสรุปเทรนด์ BTC รายวัน

daily_report.py [ใหม่] — สรุปภาพรวม BTC ส่งเข้า LINE วันละครั้ง
  แยกจาก bot.py เพราะคนละงานคนละจังหวะ: bot.py หาจุดเข้าเทรดทุกชั่วโมง
  ส่วนนี้รายงานบริบทวันละครั้ง ไม่มี Entry/SL/TP เพราะไม่ใช่สัญญาณเทรด

  ข้อมูลที่รายงาน (คำนวณจากราคา Binance ทั้งหมด ไม่พึ่งบริการนอก):
    ราคา + เปลี่ยนแปลง 24 ชม. / 7 วัน   จากราคาปิด 1H
    เทรนด์ 1D และ 4H                    จาก htf_filter.htf_structure
    RSI 1D และ 4H                       จาก divergence.rsi
    ความผันผวน                          ATR(14) เทียบ % ราคา และเทียบค่าเฉลี่ย 90 วัน
    แนวรับ / แนวต้าน                     swing pivot รายวันที่ใกล้ราคาที่สุด

  ข้อดีของการไม่พึ่งบริการนอก: ไม่มีค่าใช้จ่ายเพิ่ม ไม่ต้องมี API key เพิ่ม
  และไม่มีอะไรพังจากฝั่ง third-party

deploy/qmbot-daily.service + .timer [ใหม่] — ตั้งเวลาด้วย systemd timer
  OnCalendar=*-*-* 10:00:00 Asia/Bangkok
  ระบุ timezone ตรงๆ ไม่พึ่ง timezone ของเครื่องอย่างเดียว เผื่อถูกเปลี่ยนภายหลัง
  (ตรวจแล้วด้วย systemd-analyze calendar ว่า systemd 252 บน Debian 12 รองรับ)
  Persistent=true — ถ้า VM ปิดตอน 10 โมง พอเปิดมาจะส่งให้ ไม่ข้ามวันเงียบๆ
  Restart=on-failure RestartSec=120 — ลองใหม่ 1 ครั้งถ้า exchange/LINE ล่มชั่วคราว
  ใช้ timer แทน cron เพราะระบบใช้ systemd อยู่แล้ว และ Persistent/timezone
  ทำได้สะอาดกว่า cron

setup_vm.sh อัปเดตให้ติดตั้ง timer ตอน deploy ใหม่ด้วย

ทดสอบ: รันจริงบน VM ส่งเข้า LINE สำเร็จ (exit 0) และ timer ตั้งไว้ถูกต้อง
ครั้งถัดไป 20/08/2026 10:00 +07 บอทหลักไม่กระทบ ยัง active/enabled ปกติ
