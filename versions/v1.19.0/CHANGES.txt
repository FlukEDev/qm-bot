==================================================================
รายละเอียดการเปลี่ยนแปลง
==================================================================

ผู้ใช้เปิด repo เป็น GitHub แล้ว ต้องการให้ใครก็ตามที่เข้ามาดูสามารถนำบอท
ไปใช้ได้ โดยมีคู่มือทั้งภาษาอังกฤษและภาษาไทย

ปัญหาของ README เดิม: เขียนไว้สำหรับเจ้าของโปรเจกต์คนเดียว มี path เฉพาะเครื่อง
(/Users/fluke/...), ชื่อ VM และ zone ที่ deploy จริง, คำสั่ง gcloud ที่ชี้ไป
instance ของผู้ใช้ ซึ่งคนอื่นเอาไปใช้ไม่ได้และเป็นการเปิดเผยรายละเอียดโครงสร้าง
ระบบส่วนตัวโดยไม่จำเป็น

เขียนใหม่ทั้งสองไฟล์เป็นคู่มือสำหรับคนทั่วไป:
  - อธิบายว่าบอททำอะไร พร้อมตัวอย่างข้อความที่ได้รับจริง
  - อธิบายว่าทำไมต้อง QM (BOS คือสิ่งที่ทำให้เข้าไม้ได้เร็วกว่า H&S ธรรมดา)
  - ผล backtest จริงพร้อมข้อจำกัดของมันแบบตรงไปตรงมา
  - ขั้นตอนติดตั้งครบตั้งแต่ clone จนส่งสัญญาณแรก
  - ตารางค่าที่ปรับได้ พร้อมบอกว่าแต่ละค่าควบคุมอะไร
  - ประมาณการจำนวนสัญญาณเทียบกับโควตา LINE ฟรี
  - ข้อจำกัดที่ต้องรู้ (ไม่ใช่บอทเทรดอัตโนมัติ ไม่ใช่คำแนะนำการลงทุน
    win rate 45% เป็นเรื่องปกติ edge อาจไม่คงอยู่)
  - ลิงก์สลับภาษาไปมาได้ทั้งสองทาง (ตรวจแล้วว่า anchor ทำงาน)

ลบข้อมูลเฉพาะเครื่องออกหมด ตรวจแล้วไม่เหลือ path ส่วนตัว ชื่อ VM
ชื่อ bucket หรือ userId ใน README ทั้งสองไฟล์
