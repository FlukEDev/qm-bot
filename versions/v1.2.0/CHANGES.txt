รายละเอียดการเปลี่ยนแปลง
==================================================================

ผู้ใช้ต้องการให้บอทอ่านกราฟจาก Futures ไม่ใช่ Spot

  - เปลี่ยน exchange จาก binance เป็น binanceusdm
  - symbol เปลี่ยนรูปแบบเป็น BASE/USDT:USDT (รูปแบบของ ccxt สำหรับ perpetual)
    เพิ่มฟังก์ชัน to_perp_symbol() / display_symbol() แปลงไปมา เพื่อให้ config
    และข้อความใน LINE ยังใช้ชื่อสั้น "BTC/USDT" ที่อ่านง่าย

บั๊กที่เจอตอนทดสอบ:
  ดึง Top 100 ตามวอลุ่มแล้วพบว่ามีสัญญา TradFi ปนมาด้วย — ทองคำ (XAU),
  เงิน (XAG), หุ้น tokenized (SNDK, SKHYNIX) ซึ่งไม่ใช่คริปโต และขัดกับที่
  ผู้ใช้เลือกไว้ว่ายังไม่เอาทองในเวอร์ชันนี้
  แก้โดยกรองด้วย metadata ของ Binance เอง (contractType = PERPETUAL และ
  underlyingType = COIN) — เชื่อถือได้กว่าการเดาจากชื่อ symbol
  หมายเหตุ: PAXG/XAUT ยังอยู่ในรายการ ซึ่งถูกต้อง เพราะเป็นเหรียญคริปโต
  ที่หนุนด้วยทอง ไม่ใช่สัญญา TradFi
