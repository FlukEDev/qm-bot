สรุป: เพิ่มตัวกรองคุณภาพแท่งเทียน — BOS ต้องมีเนื้อปิดทะลุ ไม่ใช่แค่ไส้แทะ
เทียบกับ: v1.20.0

==================================================================
รายละเอียดการเปลี่ยนแปลง
==================================================================

ผู้ใช้เสนอให้ศึกษาเรื่องเนื้อเทียนกับไส้เทียนมาปรับใช้กับ QM

งานวิจัย price action ให้ตัวเลขชัดเจน:
  แท่งที่ปิด 'เนื้อ' เลยระดับ        -> ไปต่อ 59-64%
  แท่งที่ 'ไส้' ทะลุแล้วปิดกลับเข้ามา -> ไปต่อ 25-27% (ต่ำกว่าค่าฐาน ~37%)
กล่าวคือ ไส้ทะลุแล้วปิดกลับ = สัญญาณกลับตัว ไม่ใช่สัญญาณไปต่อ

QM ต้องการสองอย่างตรงข้ามกัน และโค้ดเดิมใช้ไส้เทียน (high/low) ทั้งคู่:
  HEAD ควรเป็น 'ไส้กวาด'    — ถ้าเนื้อปิดเหนือ LS แปลว่าเบรกจริง ไม่ใช่กวาด
  BOS  ควรเป็น 'เนื้อปิดทะลุ' — ถ้าแค่ไส้แทะ นั่นคือกวาดฝั่งล่าง ไม่ใช่ทำลายโครงสร้าง

ทดสอบ 9 สมมติฐานบน 98 เหรียญ / 2.59 ล้านแท่ง (out-of-sample):
  ไม่กรอง                  1578 ไม้  win 45.8%  +0.634R  PF 2.02
  HEAD กวาดด้วยไส้           863 ไม้  win 43.5%  +0.755R  PF 2.14
  HEAD เนื้อทะลุ (ตรงข้าม)   715 ไม้  win 48.5%  +0.488R  PF 1.86  <- แย่ลง
  BOS เนื้อปิดที่แท่ง L2      462 ไม้  win 50.6%  +0.966R  PF 2.74  <- ดีที่สุด
  BOS ไม่มีเนื้อปิด (ตรงข้าม) 654 ไม้  win 44.6%  +0.510R  PF 1.81  <- แย่ลง
ทั้งสองสมมติฐานถูกต้อง และการทดสอบทิศตรงข้ามก็ให้ผลแย่ลงตามที่ควรเป็น
ยืนยันว่าไม่ใช่ความบังเอิญ

เลือก 'BOS เนื้อปิดที่แท่ง L2' เป็นตัวกรองหลัก เพราะแรงที่สุด และเช็คแล้วว่า
ช่วยทั้งสองโปรไฟล์ ไม่ได้ฆ่าอันใดอันหนึ่ง (บทเรียนจาก v1.16.0):
    1h short  +0.634R -> +0.979R   win 46.7% -> 53.0%
    1h wide   +0.631R -> +0.897R   win 36.7% -> 38.4%
win rate รวมทะลุ 50% เป็นครั้งแรก (50.6%) และ PF ขึ้นเป็น 2.74

หมายเหตุ: การรวม HEAD ไส้กวาด + BOS เนื้อปิด ให้ผล +0.828R ซึ่ง 'แย่กว่า'
BOS อย่างเดียว (+0.966R) จึงไม่รวมกัน ตั้ง require_head_wick: false ไว้

สิ่งที่เพิ่ม:
  candle_quality.py [ใหม่] tag_candle_quality() + passes_candle_gate()
  config candle_quality {enabled, require_bos_body, require_head_wick}
  แถว 'BOS: เนื้อปิดทะลุ / ไส้แทะเท่านั้น' ในข้อความ LINE
  log บอกจำนวนที่ถูกกรองทิ้งต่อเหรียญ

** ผลข้างเคียงที่ต้องรู้: ตัดสัญญาณทิ้งราว 71% ** (1578 -> 462 ไม้ out-of-sample)
สัญญาณจริงจะเหลือราว 50/เดือน จาก ~170/เดือน และโควตา LINE เหลือใช้ ~80/300
ถ้าอยากได้สัญญาณเยอะเหมือนเดิม ตั้ง candle_quality.enabled: false
แล้วดูค่า BOS ในข้อความเพื่อตัดสินใจเองได้ (ค่ายังถูกติดไว้ทุกสัญญาณเสมอ)
