==================================================================
รายละเอียดการเปลี่ยนแปลง
==================================================================

ย้ายบอทจากเครื่อง Mac ไปรันบน Google Compute Engine เพื่อไม่ให้หยุด
เวลาเครื่องปิด/หลับ

  deploy/qmbot.service  [ใหม่] systemd unit — รัน bot.py --loop ในนาม user
                        qmbot โดยเฉพาะ, restart อัตโนมัติถ้า crash,
                        เริ่มเองเมื่อ VM reboot
  deploy/setup_vm.sh    [ใหม่] สคริปต์ติดตั้งบน VM (idempotent รันซ้ำได้)

ปัญหาที่เจอระหว่าง deploy:
  สร้าง VM ที่ us-central1 ก่อน (เพื่อให้เข้าเกณฑ์ Always Free tier) แต่ Binance
  ตอบ HTTP 451 "restricted location" ทันที เพราะบล็อค IP จากสหรัฐฯ ซึ่งแก้ด้วย
  โค้ดไม่ได้ และ Binance.US ก็ไม่มี futures ให้เทรด
  → ย้ายไป asia-southeast1 (สิงคโปร์) ซึ่งหลุดจาก free tier
  → ค่าใช้จ่ายประมาณ $7.65/เดือน (คำนวณจาก Cloud Billing API จริง:
     e2-micro $0.0092/ชม. + disk 20GB $0.044/GiB/เดือน)

ก่อนหน้านี้ยังได้เพิ่มออปชัน --keep-awake ใน qmbotctl.py (ใช้ caffeinate ของ
macOS กันเครื่องหลับ) ซึ่งยังใช้ได้ถ้าจะรันบน Mac แต่ไม่จำเป็นแล้วเมื่อรันบน VM
