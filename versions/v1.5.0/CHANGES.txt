เวอร์ชัน: v1.5.0
วันที่: 2026-08-18
สรุป: แก้ให้สแกนตรงนาทีที่ 01 ของทุกชั่วโมง (แท่งเทียนปิดพอดี)
เทียบกับ: v1.4.0

==================================================================
รายละเอียดการเปลี่ยนแปลง
==================================================================

ผู้ใช้แจ้งว่าแท่งเทียนปิดตอนจบชั่วโมง ต้องการให้บอทสแกนที่นาทีแรกของทุกชั่วโมง

ปัญหาเดิม: bot.py ใช้ time.sleep(interval) แบบตายตัว ทำให้เวลาสแกนเลื่อนไปตาม
เวลาที่เผอิญ start ไว้ เช่นถ้า start ตอน 14:47 ก็จะสแกน 15:47, 16:47 ไปเรื่อยๆ
ซึ่งช้ากว่าแท่งปิดเกือบ 47 นาที เสี่ยงที่สัญญาณจะเก่าเกิน fresh_bars แล้วถูกข้าม

วิธีแก้: เพิ่มฟังก์ชัน _seconds_until_aligned() คำนวณวินาทีที่ต้องรอจนถึง
ขอบชั่วโมงถัดไป + 1 นาที แล้ว sleep เท่านั้นพอดีในทุกรอบ
ใช้ time.time() (UTC epoch) จึงถูกต้องไม่ว่าเครื่องจะตั้ง timezone อะไร

ทดสอบ: รันจริงแล้วเห็น log "next scan in 3548s (aligned to :01 past each 60m
boundary)" และตรวจสอบบน VM ว่าสแกนตรงเวลา 00:01, 01:01, ... 13:01 ติดต่อกัน
15 ชั่วโมงโดยไม่เลื่อน
