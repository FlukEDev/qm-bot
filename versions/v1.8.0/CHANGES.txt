สรุป: เพิ่มระบบเก็บเวอร์ชันแยกโฟลเดอร์พร้อมบันทึกการเปลี่ยนแปลง
เทียบกับ: v1.7.0

==================================================================
รายละเอียดการเปลี่ยนแปลง
==================================================================

ผู้ใช้ต้องการให้ทุกการเปลี่ยนแปลงถูกเก็บแยกโฟลเดอร์ตามเวอร์ชัน พร้อมไฟล์
text อธิบายว่าเปลี่ยนอะไร โดยให้ทำย้อนหลังตั้งแต่เริ่มโปรเจกต์ และทำต่อเนื่อง
ทุกครั้งที่มีการเปลี่ยนแปลงในอนาคต

สิ่งที่เพิ่ม:
  make_version.py  [ใหม่] สคริปต์สร้าง snapshot เวอร์ชันใหม่
                   - คัดลอกโค้ดปัจจุบันไป versions/vX.Y.Z/code/
                   - เทียบกับเวอร์ชันก่อนหน้า สรุปไฟล์ที่ เพิ่ม/แก้/ลบ
                   - สร้าง CHANGES.txt และอัปเดตสารบัญ INDEX.md ให้อัตโนมัติ
                   - กันไฟล์ความลับ (.env, signals.db, userid.txt, log, รูป,
                     ข้อมูล cache) ไม่ให้ถูกคัดลอกเข้า snapshot เด็ดขาด
                     เพราะโฟลเดอร์ versions/ ถูก commit ขึ้น git

  versions/        [ใหม่] บันทึกย้อนหลังครบทั้ง 11 เวอร์ชันตั้งแต่ v1.0.0
                   พร้อมสารบัญที่ INDEX.md

เรื่องสำเนาโค้ดย้อนหลัง:
  v1.6.0 และ v1.7.0 มีสำเนาโค้ดจริง เพราะกู้จาก git commit ได้
  (1cd12f1 และ 7e82f5d ตามลำดับ)
  ส่วน v1.0.0-v1.5.0 มีแต่บันทึกการเปลี่ยนแปลง ไม่มีสำเนาโค้ด เพราะโค้ดตอนนั้น
  ถูกแก้ทับไปแล้วโดยไม่ได้ commit แยกไว้ การสร้างขึ้นใหม่ย้อนหลังจะได้ไฟล์ที่
  ไม่เคยถูกทดสอบจริง ซึ่งจะทำให้เข้าใจผิดมากกว่ามีประโยชน์ จึงเลือกไม่ทำ

  ตั้งแต่เวอร์ชันนี้เป็นต้นไป ทุกเวอร์ชันจะมีสำเนาโค้ดครบ

  เพิ่มคำอธิบายวิธีใช้ระบบนี้ใน README ทั้งสองภาษาแล้ว
